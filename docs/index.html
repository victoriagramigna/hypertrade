Para que el sistema te avise por mail (stop tocado, objetivo de ganancia, pérdida de fuerza técnica) incluso sin tener esta página abierta, conectá esta cartera con GitHub -- una sola vez. Después, cada compra o venta que anotes se sincroniza sola, sin que tengas que copiar ni pegar nada.
✓ Sincronización automática activada
Para conectar, necesitás un token de GitHub con permiso solo sobre este repo:
1. Andá a github.com/settings/personal-access-tokens/new
2. "Repository access" → "Only select repositories" → elegí hypertrade
3. En "Permissions" → "Repository permissions" → "Contents" → cambiá a "Read and write"
4. "Generate token" y copiá el código (empieza con github_pat_...)
El token queda guardado solo en este navegador, igual que tu cartera -- nunca se sube al repo.
