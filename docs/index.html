Para que el sistema te avise por mail (stop tocado, objetivo de ganancia, pérdida de fuerza técnica) incluso sin tener esta página abierta, conectá esta cartera con GitHub -- una sola vez. Después, cada compra o venta que anotes se sincroniza sola, sin que tengas que copiar ni pegar nada.
✓ Sincronización automática activada
Para conectar, necesitás un token de GitHub con permiso solo sobre este repo:
1. Andá a github.com/settings/personal-access-tokens/new
2. "Repository access" → "Only select repositories" → elegí hypertrade
3. En "Permissions" → "Repository permissions" → "Contents" → cambiá a "Read and write"
4. "Generate token" y copiá el código (empieza con github_pat_...)
El token queda guardado solo en este navegador, igual que tu cartera -- nunca se sube al repo.

Posiciones

Auditoría

Cómo terminaron las señales, medido con precios reales. Una señal alcista acierta si el precio subió; una bajista, si bajó. Con pocos casos los números todavía no significan nada: mirá siempre cuántos casos respaldan cada resultado.

Medir a:

Mis operaciones

Tus compras y ventas reales, cargadas en Mi Cartera con el botón Vender. Las señales dicen si el radar acierta; esto dice si tu forma de operar gana plata.

Resultados por señal

Evolución mes a mes

Todas las señales juntas, agrupadas por el mes en que se dispararon. Sirve para ver si la app acierta de forma sostenida o solo tuvo algunas semanas buenas. "A favor" cuenta como ganancia que una señal bajista haya bajado.

Según el régimen de mercado

Señales alcistas agrupadas por el régimen que había cuando se dispararon. Si el régimen sirve, las franjas altas deberían acertar más. Cuenta desde que el régimen empezó a grabarse.

Según los puntos de cuidado

Señales alcistas con y sin advertencias (SMA50 bajando, techo en el AVWAP, extendida, etc.). Si las advertencias sirven, las que tienen puntos de cuidado deberían rendir peor. Cuenta desde que se empezaron a grabar.

Top 30 de cada semana

El primer día de cada semana se guarda el Top 30 de Fuerza Relativa. Acá se ve si le ganó al SPY y al promedio de todo el universo.
